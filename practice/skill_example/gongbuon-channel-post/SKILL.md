# 공부ON 채널별 홍보 문구 만들기

## 작업 순서
1. 원고에서 **핵심 메시지 1개**, **혜택·안내 1개**(상담, 특별 관리 등), **행동 요청 1개**(예약, 문의)를 먼저 뽑아 보여준다.
2. 아래 채널 규칙대로 3종을 만든다.
3. 마지막에 "검수 체크" 표를 붙인다: 날짜·시간·가격이 원고와 같은지, 금지 표현이 없는지.

## 채널 규칙
| 채널 | 길이 | 말투 | 꼭 넣을 것 |
|---|---|---|---|
| 당근 소식 | 제목 20자 이내 + 본문 300자 이내 | 이웃에게 말하듯 편하게 | 동네 이름 대신 "우리 동네", 상담 시간 |
| 네이버 플레이스 소식 | 본문 400자 이내 | 정돈된 안내문 | 대상, 기간, 상담 방법을 줄바꿈으로 구분 |
| 인스타그램 캡션 | 첫 줄 15자 이내 훅 + 본문 5줄 이내 | 짧고 리듬감 있게 | 해시태그 5~8개(맨 끝), 이모지는 줄마다 최대 1개 |

## 지킬 것
- 원고에 없는 숫자(성적 향상 폭, 할인율, 합격 실적)는 만들지 않는다.
- "무조건", "100% 성적 향상", "최고", "1등" 같은 과장 표현은 쓰지 않는다.
- 학생 실명·학교명은 넣지 않는다.
- 공부ON 표기는 항상 `공부ON`(영문 대문자 ON).

## 결과 형식
```
[당근 소식]
제목: …
본문: …

[네이버 플레이스 소식]
…

[인스타그램 캡션]
…

[검수 체크]
| 항목 | 결과 |
```
