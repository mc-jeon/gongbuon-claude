0. 작업 환경 준비한 번만 하면 됩니다 · 약 30분

왜 설치하나요? 지금 쓰는 Claude 앱(대화창)은 말로 답하는 도구입니다. 오늘 설치하는 Claude Code는 내 PC에서 파일을 옮기고, 크롬을 움직이고, 표를 만드는 도구입니다. 글자로 명령하는 검은 창(CLI)에서 쓰지만, 명령어를 외울 필요는 없습니다. 한국어로 부탁하면 됩니다.
STEP 0-1

PowerShell 열기

🎯 명령을 입력할 검은 창(PowerShell)을 엽니다.
  1. 키보드 Win 키 누르기
  2. 검색창에 powershell 입력
  3. Windows PowerShell 클릭
파란색(또는 검은색) 창에 PS C:\Users\…> 가 보이면 성공입니다.
'관리자 권한' 창이 뜨면 그냥 닫고 일반 PowerShell로 다시 여세요. 오늘 실습은 관리자 권한이 필요 없습니다.
STEP 0-2

Git·Python 설치

🎯 Claude Code가 쓰는 기본 도구 두 가지를 설치합니다.
  1. 아래 상자의 전체 복사 클릭
  2. PowerShell 창에 마우스 오른쪽 클릭(또는 Ctrl+V) → Enter
  3. 중간에 '계약 조건에 동의하십니까?'가 나오면 Y → Enter
  4. 두 줄 모두 '설치됨'이 나오면 PowerShell 창을 닫았다가 다시 열기
📄 Git·Python 설치 · 2줄

winget install --id Python.Python.3.12 -e
마지막에 설치됨(또는 Successfully installed)이 두 번 보이면 성공입니다.
'winget을 찾을 수 없습니다'가 나오면 Microsoft Store에서 앱 설치 관리자를 업데이트한 뒤 다시 하세요.
STEP 0-3

Claude Code 설치·로그인

🎯 Claude Code를 설치하고 지금 쓰는 Claude 계정으로 로그인합니다.
  1. 아래 명령 복사 → PowerShell에 붙여넣기 → Enter
  2. 설치가 끝나면 창을 닫고 다시 열기
  3. claude 입력 → Enter
  4. 글자 색 고르기 화면은 Enter로 넘기기
  5. 로그인 방법에서 Claude account with subscription 선택 → 브라우저에서 승인(Authorize)
📄 Claude Code 설치 · 1줄

창에 Welcome to Claude Code와 입력칸(>)이 보이면 성공입니다.
'claude 명령을 찾을 수 없습니다'가 나오면 PowerShell을 완전히 닫고 새로 여세요. 그래도 안 되면 PC를 다시 시작합니다.

🎯 세 가지가 모두 제대로 설치됐는지 확인합니다.

구글 드라이브 데스크톱 설치

  2. 내려받은 파일 실행 → 설치
  3. Gemini 유료 구독 중인 구글 계정으로 로그인 (2TB 저장 공간이 있는 계정)
  4. 파일 탐색기 왼쪽에 Google Drive (G:) 가 생겼는지 확인

폴더에서 Claude Code 열기

🎯 작업할 폴더 안에서 Claude를 실행합니다. 그래야 그 폴더만 다룹니다.
  1. 탐색기에서 바탕 화면 → usb_sample 폴더 열기
  2. 위쪽 주소창 클릭
  3. powershell 입력 → Enter
  4. 열린 창에 claude 입력 → Enter
  5. '이 폴더의 파일을 신뢰합니까?'에서 Yes, proceed 선택
Claude Code 화면 위쪽에 …\Desktop\usb_sample 경로가 보이면 성공입니다.
STEP 1-3

분류표 먼저 받기

🎯 바로 옮기지 않고, 어떻게 나눌지 표로 먼저 받아 봅니다.
  1. 아래 프롬프트 복사 → Claude 입력칸에 붙여넣기 → Enter
  2. Claude가 보여 준 분류표 읽기
  3. 바꾸고 싶은 게 있으면 말로 고치기(예: '견적비교는 홍보 말고 정산서류로')
이 폴더에 있는 파일을 전부 살펴보고, 아래 폴더로 나누는 분류표를 먼저 보여줘. 아직 옮기거나 복사하지 마. [분류 폴더] 01_시간표 / 02_상담 / 03_홍보 / 04_정산서류 / 99_확인필요 [규칙] - 파일 이름만으로 애매하면 내용을 열어 보고 판단해 - 그래도 모르겠으면 99_확인필요로 - 표: 파일명 | 분류 | 이유(한 줄)
표에 21개 파일이 모두 있고, 대략 시간표 5 · 상담 4 · 홍보 6 · 정산서류 4 · 확인필요 2로 나뉘면 성공입니다(조금 달라도 괜찮습니다. 내가 고치면 됩니다).
STEP 1-4

드라이브로 복사

🎯 확인한 분류대로 G 드라이브에 폴더를 만들고 복사합니다.
  1. 아래 프롬프트 복사 → 붙여넣기 → Enter
  2. Claude가 명령 실행 허락을 물으면 내용 읽고 1. Yes 선택
  3. 복사가 끝났다는 메시지 기다리기
좋아, 그 분류대로 진행해줘. - 복사할 곳: G:\내 드라이브\공부ON_백업\ - 분류 폴더를 만들고 그 안에 복사 - 원본은 절대 지우거나 옮기지 마 (복사만) - 끝나면 폴더별 파일 개수를 알려줘
Claude가 자꾸 '허락'을 묻는 이유 파일을 만들거나 복사하는 명령은 실행 전에 꼭 물어봅니다. 1. Yes는 이번 한 번, 2. Yes, and don't ask again…은 같은 종류를 계속 허락합니다. 처음에는 1번으로 하나씩 보세요. '삭제(Remove, del)'가 들어간 명령이면 3. No를 누르고 이유를 물어보세요.
탐색기 Google Drive (G:) › 내 드라이브 › 공부ON_백업에 폴더 5개가 생기면 성공입니다.
'G: 경로를 찾을 수 없습니다'가 나오면 0-5의 드라이브 글자를 확인하고 프롬프트의 G: 를 바꾸세요.

  2. 합계가 같은지 확인
  3. 브라우저에서 drive.google.com 을 열어 같은 폴더가 보이는지 확인
원본 폴더와 G:\내 드라이브\공부ON_백업 을 비교해서 폴더별 파일 개수, 전체 개수, 전체 용량을 표로 보여줘. 빠진 파일이 있으면 이름을 알려줘.
원본 21개 = 복사본 21개, '빠진 파일 없음'이 나오면 성공입니다. 웹 드라이브에는 몇 분 뒤에 나타날 수 있습니다(동기화 중).

  2. 커넥터 클릭
  3. Google Drive 옆 연결 → 같은 구글 계정 선택 → 허용
  4. 새 대화에서 아래 프롬프트로 시험
내 구글 드라이브에서 '공부ON_백업' 폴더를 찾아서, 안에 있는 폴더와 파일 개수를 알려줘.
Claude가 폴더 5개와 파일 개수를 답하면 성공입니다. 같은 계정으로 로그인한 Claude Code에서도 이 연결을 함께 씁니다.
예전 화면에서는 설정 → 커넥터에 있습니다. '연결됨'인데 못 찾으면 새 대화에서 다시 물어보세요.

  2. USB 안 작업 폴더에서 1-2처럼 Claude Code 열기

# 공부ON 채널별 홍보 문구 만들기

## 작업 순서
1. 원고에서 **핵심 메시지 1개**, **혜택·안내 1개**(상담, 특별 관리 등), **행동 요청 1개**(예약, 문의)를 먼저 뽑아 보여준다.
2. 아래 채널 규칙대로 3종을 만든다.
3. 마지막에 "검수 체크" 표를 붙인다: 날짜·시간·가격이 원고와 같은지, 금지 표현이 없는지.

## 채널 규칙
| 채널 | 길이 | 말투 | 꼭 넣을 것 |
|---|---|---|---|
| 당근 소식 | 제목 20자 이내 + 본문 300자 이내 | 이웃에게 말하듯 편하게 | 동네 이름 대신 "우리 동네", 상담 시간 |
| 네이버 플레이스 소식 | 본문 400자 이내 | 정돈된 안내문 | 대상, 기간, 상담 방법을 줄바꿈으로 구분 |
| 인스타그램 캡션 | 첫 줄 15자 이내 훅 + 본문 5줄 이내 | 짧고 리듬감 있게 | 해시태그 5~8개(맨 끝), 이모지는 줄마다 최대 1개 |

## 지킬 것
- 원고에 없는 숫자(성적 향상 폭, 할인율, 합격 실적)는 만들지 않는다.
- "무조건", "100% 성적 향상", "최고", "1등" 같은 과장 표현은 쓰지 않는다.
- 학생 실명·학교명은 넣지 않는다.
- 공부ON 표기는 항상 `공부ON`(영문 대문자 ON).
